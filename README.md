# RPG‑игра: выбор класса и тренировка навыков

Простая консольная RPG‑игра на языке Go, в которой игрок выбирает класс персонажа (Воитель, Маг или Лекарь), знакомится с его особенностями и тренирует базовые навыки: атаку, защиту и специальное умение.

## Функциональность

Игра предлагает следующий игровой цикл:

1. Приветствие игрока и запрос имени персонажа.
2. Выбор класса персонажа с кратким описанием каждого:
   * **Воитель** (`warrior`) — сильный боец ближнего боя.
   * **Маг** (`mage`) — воин дальнего боя с высоким интеллектом.
   * **Лекарь** (`healer`) — заклинатель, черпающий силы из природы.
3. Подтверждение выбора класса.
4. Тренировка навыков: игрок может по очереди использовать команды `attack`, `defence` и `special`, чтобы увидеть, как работает каждый навык для выбранного класса.
5. Выход из тренировки по команде `skip`.

## Классы и их характеристики

| Класс | Атака (attack) | Защита (defence) | Специальное умение (special) |
|------|---------------|------------------|----------------------------|
| Воитель (`warrior`) | $8–10$ урона | $15–20$ блокируемого урона | «Выносливость $105$» |
| Маг (`mage`) | $10–15$ урона | $8–12$ блокируемого урона | «Атака $45$» |
| Лекарь (`healer`) | $2–4$ урона | $12–15$ блокируемого урона | «Защита $40$» |

## Доступные команды во время тренировки

* `attack` — нанести урон противнику.
* `defence` — заблокировать урон от атаки противника.
* `special` — применить уникальное специальное умение класса.
* `skip` — завершить тренировку и выйти из игры.
